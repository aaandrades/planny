# Planny 🚗

A road-trip planner PWA for two (or more). Import a plan generated by AI, follow it day by day, tick things off together, and keep working offline when you lose signal.

**Stack:** React 19 + TypeScript + Vite + SCSS modules · Vercel serverless functions (Node) · MongoDB Atlas · `vite-plugin-pwa`.

## Features

- **Trips home:** your current or next trip as a big hero card with a countdown, plus upcoming and past trips.
- **AI import:** copy the built-in prompt, paste the AI's JSON, and get a live-validated preview. See [docs/TRIP_FORMAT.md](docs/TRIP_FORMAT.md).
- **Day-by-day plan:** a strip to pick the day (opens on today automatically), a timeline of stops, tips, costs, a hotel card, and "Navigate" / "Open route" buttons that open Google Maps.
- **Map:** every stop on a map with a colored route per day. Loaded only when you open the tab. Tiles you've viewed stay cached for offline use.
- **Shared checklist and notes.** Edits never overwrite each other, so you can both tick things at once.
- **Offline-first:** the app opens instantly from cache. Ticks made offline are queued and synced when you reconnect.
- **Simple login:** pick your name and enter a PIN. The session lasts 180 days.
- Light and dark mode, installable on iOS and Android.

## 1. Set up MongoDB Atlas (free)

1. Create a free **M0** cluster at <https://cloud.mongodb.com>.
2. Under **Database Access**, add a database user with a password.
3. Under **Network Access**, add `0.0.0.0/0`. Vercel's IP addresses change, so the cluster has to accept connections from anywhere. The password still protects it.
4. Go to **Connect → Drivers** and copy the connection string.

You don't need to create any collections. The app uses one database (`MONGODB_DB`, default `planny`) with a single `trips` collection that it creates, along with its index, the first time you save a trip. Each trip is one document. Logins aren't stored in the database; they come from `PLANNY_USERS`.

## 2. Run locally

Requires **Node 20+**.

```bash
npm install
cp .env.example .env    # then fill in the values
npm run dev             # http://localhost:5173 (serves the app and /api)
```

`.env`:

| Variable          | Example                              | What it does                         |
| ----------------- | ------------------------------------ | ------------------------------------ |
| `MONGODB_URI`     | `mongodb+srv://…`                    | Atlas connection string              |
| `MONGODB_DB`      | `planny`                             | Database name                        |
| `PLANNY_USERS`    | `Andres:1234,Wife:5678`              | Who can log in, as `name:PIN` pairs  |
| `SESSION_SECRET`  | output of `openssl rand -hex 32`     | Signs the login cookie               |

## 3. Deploy to Vercel

1. Push this folder to a GitHub repo and import it at <https://vercel.com/new>. The framework is detected as Vite.
2. Add the four environment variables above under **Settings → Environment Variables**.
3. Deploy. Every push redeploys automatically.

## 4. Install on your phones

- **iPhone (Safari):** Share → **Add to Home Screen**
- **Android (Chrome):** ⋮ → **Install app**

## Project layout

```
api/                Vercel functions (Web Request → Response handlers)
  _lib/             db, auth, http helpers (underscore = not a route)
  auth/             login · logout · me
  trips/            index (list/create) · [id] (get/replace/patch/delete)
shared/trip.ts      zod schema + types used by both API and UI
src/
  lib/              api client, offline cache, sync queue, formatting
  components/       Button, Sheet, TripCard, ImportSheet, …
  pages/            Login, Home, TripPage (+ trip/ tabs)
  styles/           global tokens (CSS variables) + SCSS mixins
public/             logo + sample-trip.json
docs/               trip format guide
```

## Changing things

- **Colors:** CSS variables at the top of [`src/styles/global.scss`](src/styles/global.scss), with light and dark sets.
- **Users and PINs:** change `PLANNY_USERS` in Vercel and redeploy. Anyone removed is logged out.
- **Trip format:** [`shared/trip.ts`](shared/trip.ts). Update [`src/lib/aiPrompt.ts`](src/lib/aiPrompt.ts) to match.
